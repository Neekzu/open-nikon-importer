# Roadmap

## Public 0.1

- Package a downloadable macOS `.dmg`.
- Document Nikon ZR support clearly.
- Add GitHub issue templates for compatibility reports.
- Keep manual release downloads until signing/notarization is ready.

## Compatibility

- Test additional Nikon cameras in MTP/PTP mode.
- Record per-camera support notes for `.NEV`, `.NEF`, `.MOV`, `.MP4`, and proxy workflows.
- Add a safe diagnostics export that includes camera model, PTP operations, object formats, and app errors without media content.

## Workflow

- Improve thumbnail caching.
- Add import presets for shoot/date/project folders.
- Add duplicate detection before import.
- Add optional checksum verification for large video files.

## Updates

- Add Sparkle 2 after Developer ID signing, notarization, EdDSA signing, and appcast hosting are ready.
